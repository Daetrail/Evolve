# Backend MVP Features Roadmap

## Fitness
1. Basic user authentication (username, email, password)
2. Create exercise (name, muscles worked)
  - pre-defined common exercises
3. Create workout (list of exercises + sets with details (load, reps, rir) per exercise)
4. Create program (list of workouts)
  - pre-defined common programs (ulul, ulppl, fbeod, pplppl)
5. Data visualisation (total volume, volume/sets per muscle group, e1RM/e3RM)
